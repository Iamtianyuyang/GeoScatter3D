### 关键结论与坑（复用价值高）

1. **Bash 工具环境被剥离**：`ProgramFiles` / `ProgramFiles(x86)` / `APPDATA` /
   `SystemRoot` / `ComSpec` / `windir` 全为空。影响：
   - `flutter build windows` 报 `%PROGRAMFILES(X86)% environment variable not found`。
     修复：`env 'ProgramFiles(x86)=C:\Program Files (x86)'` 并 export 其余变量。
   - MSBuild 报 `error MSB6001 ... 字典中的关键字:"https_proxy"所添加的关键字:"HTTPS_PROXY"`。
     根因：环境同时存在大小写两份代理变量，.NET 环境字典大小写不敏感。
     修复：build 前 `unset http_proxy https_proxy no_proxy`。
   - 本机代理会劫持 flutter_tester 的 localhost WebSocket，需
     `NO_PROXY=localhost,127.0.0.1,::1`。
2. **项目不是 `dart format` 风格**：未改动文件跑 `dart format --set-exit-if-changed`
   也会变更，故禁止全局格式化，只手工修缩进。
3. **PE 导出表自写解析脚本不可靠**，核验 DLL 符号直接用字节串搜索
   `b'gs3d_engine_create'`。
4. **真实缺陷 1（我引入的回归）**：`gs3d_engine_create` 在 `shader_dir == nullptr`
   时不回退，`HeadlessRenderKernel` 遂用相对 `assets/shaders/point.vert.spv`；
   进程 cwd 非仓库根即取不到着色器（create 成功但管线失败）。已在 C++ 侧对空
   shader_dir 统一回退到 `resolve_default_shader_dir()`。
5. **真实缺陷 2**：`_openWithLocalDeps` 里 `SetDllDirectoryA` 会改写相对路径基准，
   含 `..` 的候选路径必然失败（Windows error 126）→ 先绝对化再 open。
6. **陈旧产物**：`ui_flutter/gs3d_ffi.dll` 曾是旧构建（无引擎符号），

- **`testWidgets` 里建服务必须走 `tester.runAsync`（高价值坑）**：
  `GeoScatter3dService.initialize()` / `loadDataset()` 会拉起 `Timer.periodic`
  （指标轮询 / 拖放轮询 / 原生帧泵）。若在测试默认的**假时钟区**里调用，
  `AutomatedTestWidgetsFlutterBinding._verifyInvariants` 会断言
  `!timersPending` 失败（`A Timer is still pending even after the widget tree
  was disposed`），且 `shutdown()` 清不干净；更迷惑的是用例常表现为
  **每条都等满 10 分钟超时**（截图/断言其实早已完成）。
  正确写法（与仓库既有约定一致，见 `test/welcome_backend_integration_test.dart`）：
  ```dart
  await tester.runAsync(() async { service.initialize(); });
  addTearDown(() async {
    await tester.runAsync(() async {
      await service.stopNativeRenderer();
      service.shutdown();
    });
  });
  ```
  注意 `shutdown()` 内部用 `unawaited(stopNativeRenderer())`，同步段只取消帧泵
  等定时器，异步段（`Isolate.run` 释放引擎）需要真实事件循环。
- **诊断方法论**：`print` 要等用例结束才由测试报告器刷出，定位卡死必须直接把
  计时写文件（本工具写 `tmp/ui-preview/_timing.log`）；用最小对照探针
  （逐层剥离「只建服务 / 建服务+泵界面 / 只泵界面」）比反复猜更快。
