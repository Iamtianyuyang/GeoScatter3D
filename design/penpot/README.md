## 如何在 Penpot 中直接导入与编辑

1. 打开并登录 [Penpot](https://design.penpot.app/)；
2. 新建或进入一个项目（Project）；
3. 打开或新建一个画板（Artboard）；
4. 将本地文件 **`design/penpot/geoscatter3d_welcome_macos.svg` 直接拖拽到 Penpot 画布中心**；
5. Penpot 会自动将其识别为包含 `sidebar`、`top-titlebar`、`action-cards`、`illust-dotted-curve`、`illust-wireframe-box`、`illust-flowing-waves`、`recent-projects-section` 等语义化命名的矢量图层，支持自由缩放、微调文字、修改配色与组件解组。

## 设计细节与结构映射

1. **左侧边栏 (Sidebar - 220px)**
   - 顶部：macOS 红黄绿交通灯三色控件（`#FF5F56`, `#FFBD2E`, `#27C93F`）
   - 品牌：`GeoScatter3D`（18px 粗体）与版本 `v2.0 · Multiplatform`（11px 浅灰）
   - 导航项：
     - `📁 文件`（当前激活状态，淡蓝圆角胶囊底色 `#EBF5FF` + 左侧高亮指示条）
     - `🕒 最近项目`
     - `📦 示例`
     - `❓ 帮助`
   - 底部：`● RTX 4070 ⌄` 硬件加速状态与 `Compute ready` 绿色指示灯

2. **右侧主内容区 (Main Content)**
   - 标题区：页面主标题 `文件`（28px 粗体）与功能副标题
   - 第一区块：**新建或打开项目**
     - **卡片 1（新建工程）**：顶部为地形起伏散点线框图，底部为 `+ 新建工程` 及说明文字
     - **卡片 2（打开工程）**：顶部为三维线框包围盒与漂浮散点图，底部为 `📁 打开工程` 及说明文字
     - **卡片 3（快速体验示例）**：顶部为三层流动等高线曲面线框图，底部为 `▷ 快速体验示例` 及说明文字
     - 底部主按钮：macOS 经典蓝色 `打开文件…`（`#007AFF`，圆角 6px）
   - 第二区块：**最近打开的项目**
     - 表头：`项目名称`、`路径`、`最后打开时间`、右侧 `清除` 快捷链接
     - 表格项：左侧配备波形微图标徽章，支持名称、完整绝对路径与时间展示，右侧带有操作省略号 `···`
